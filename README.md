# vorc-trainer（VORC トレーニング）

画面のまん中の数字を見たまま、手に持ったスマホと頭を**いっしょに**右・左・上・下・斜めへ動かす。
顔がカメラの真ん中からずれた分（＝カメラから見た頭の向きの変化）を **VORC（前庭眼反射の抑制）のエラー**として測り、練習する（2026-10-18 宮崎さん）。

- 公開先：https://hokutomiyazaki-arch.github.io/vorc-trainer/（カメラは https でないと起動しないので GitHub Pages）
- 部品の元：カメラ・顔の点・音声・位置合わせ・FNT の外まわりは `~/FNT-Apps/hanasaki-awase`（その元は `fnt-camera-check`）をそのまま写した
- 道具：MediaPipe FaceLandmarker（tasks-vision 1.1.0・CDN）の顔の向きの行列。映像は端末の外へ送らない
- 記録はこの端末（localStorage の `vorc_runs`・最新30件）

## 2つのモード
- **トレーニング**：向き（左右・上下・斜め・全部）と速さ（1往復 ゆっくり3秒・ふつう2秒・はやい1.2秒）を選ぶ。各向き5往復。
  動かしている間、数字のまわりの**円**と**点**（点＝スマホから見て頭がずれている向き。数字の後ろに隠れていればずれていない）と「ずれ ◯°」を出す。円の色 緑＝3°未満・黄＝6°未満・赤。1つの向きが終わるごとに平均と「3°未満の時間」を出す
- **テスト**：8つの向き × 3往復・ふつう（1往復2秒）で固定。途中は何も出さず（映像も暗く）、終わってから向きごとの「平均・最大・ずれた向き」と8本の線の図を出す

## 1つの向きの流れ（runSet）
1. 楽にして1.2秒：このときの頭の向きを「ずれ0」にする（向きごとに取り直す）
2. 向きを字と声で出す → 低い音2つで構え
3. 高い音＝真ん中から出る・低い音＝向けた先から戻る、で reps 往復

## 読み（analyzeSet）
- ずれ＝カメラから見た頭の回旋・上下が、楽にしたときから動いた角度（度）。＋＝本人の右・上
- 平均・最大（大きい方から5%の所）・3°未満の時間の割合
- along＝動いている向きに沿った成分（往復の前半は向けた向き、後半は逆向きで符号をそろえる）。＋＝頭が先に行く＝「スマホが遅れる」、−＝「スマホが先に行く」。音に合わせて動いている前提なので目安
- cross＝動かす向きと直角にそれた分（例：右へ動かして上にそれる）
- ジャイロ（devicemotion の rotationRate）で、1往復ごとに動かした角度と一番速い回転を測る。**顔がずれないのが正解なので、カメラだけでは「動かしていない」と区別できない**ため。向き（符号）は端末で違うことがあるので大きさだけ使う。8°未満は「動きが小さめ」（仮）
- 目の向きの値（blendshapes の eyeLook*）も記録だけしている（`gaze`。画面には出さない）

## しきい値（すべて仮。宮崎さんが決めたら `VC`・`MOVE_MIN` を書き換える）
- `VC = { ok: 3, warn: 6, range: 10 }`（度）・`MOVE_MIN = 8`（度）
- カメラは回旋を8割・上下を半分ほどに小さく読む（fnt-camera-check で実測）ので、度は目安。どこからを問題とするかは決めていない

## 音声
- `voice/*.mp3` は hanasaki-awase の音声からコピー＋新しい3文を ElevenLabs（eleven_v3・リョウ）で作った。対応表は `voice/index.json`
- 文を変えたら `python3 tools/voice_build.py`（`--dry` で一覧と字数。鍵は `~/.zshenv` の ELEVENLABS_API_KEY）

## 更新のしかた

## 試し方（作り物のカメラ）
- `python3 -m http.server 8765` で開き、`node _test/run.mjs train`（または `test`）。Chrome を作り物のカメラ（`_test/face.y4m`。git に入れない）で起動し、最後まで通して結果とスクショを `_test/` に出す
- `?test=1` のときだけ `window.__hpFake`（頭の向きを差し替える関数）と `window.__vorc` が効く。Service Worker も登録しない
- 2026-10-18：右・右上・右下だけ 6° 揺れる頭を作って通し、右の向きだけ平均 3.9°、ほかは 0.8° と出た（トレーニング・テストとも）。**実際のスマホと頭の動きでは未確認**
